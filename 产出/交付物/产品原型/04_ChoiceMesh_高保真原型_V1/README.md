# ChoiceMesh 高保真原型 V1

打开 `index.html` 即可体验。

这版聚焦正式产品界面，而非测试场景：已移除测试员控制、重复的房间状态与长篇规则解释。保留并补全的核心路径是：

`创建共同空间 → 当前行动 → 我的条件 → 候选比较 → 暂定 → 明确发布 → 发布后调整 / 重比`

“新活动”只初始化房间，不会赋予创建者额外权限。发布后的“调整 C 的细节”可实际修改时间和费用，并将成员带回协调状态；已发布版本不会被覆盖。

共同页面只显示匿名状态；“我的条件”只展示当前成员自己的信息。静态网页仅演示信息与交互边界，真实产品仍需通过服务端身份验证、字段级授权和通知服务来保证隐私与同步。
