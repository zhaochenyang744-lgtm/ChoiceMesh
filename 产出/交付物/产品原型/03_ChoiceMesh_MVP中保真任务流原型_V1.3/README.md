# ChoiceMesh MVP 中保真任务流原型

打开 `index.html` 即可体验。V1.3 在确认性任务型回测后迭代；所有成员共用同一套界面，覆盖成员本人确认或无法参加、候选比较、暂定、最终发布和发布后问题回流。

推荐体验路径：当前待办 → 对比“尚未提交反馈 / 已回复，待核实” → 发送私密提醒并查看冷却状态 → 我的条件选择“我需要更多时间”、自行选择预计时间或确认交通 → 展开“测试员控制”模拟收到一位成员本人反馈 → 候选比较 → 暂定 C → 发布 → 优先调整 C 的细节，或重新比较候选后的无备选下一步。

“测试员控制”仅用于原型演示，不属于正式产品；共同工作区中的任何成员都不能替他人提交或确认信息。共同页的风险提示只供知情，不会变成待办；按最低人数继续时，原型将风险类别降精度为“存在已验证风险”，避免小群体反推归属。静态原型不能替代真实产品中的登录、授权、通知与服务端访问控制。
