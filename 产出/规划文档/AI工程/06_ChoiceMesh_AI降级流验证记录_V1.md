## 验证场景

| 场景 | 预期 | 结果 |
| --- | --- | --- |
| 不调用 AI，直接手动填写 | 生成空白可编辑草稿，可确认并回到匿名群体状态 | 通过 |
| API 返回超时 | 不写入确认状态；演示模式生成标记清楚的本地草稿 | 通过 |
| 上游服务失败 | 不写入确认状态；显示本地降级提示并允许逐字段修改 | 通过 |
| 返回无效 JSON | 丢弃无效输出；进入同一可编辑降级路径 | 通过 |

自动化还检查了：本地草稿把 `should be able` 保持为 `uncertain`、正确抽取 `$50`，以及手动确认后群体侧只出现匿名状态提示。

## 产品改动

详情页新增 `Enter details manually`，用户无需先调用 AI 即可建立空白结构化草稿。AI 因此是加速器，不是完成流程的前置条件。

## 证据边界

本记录证明本地演示中的四条可见路径可走通；它不等同于真实网络 20 秒超时、第三方配额耗尽、多实例故障或生产环境灾难恢复测试。
