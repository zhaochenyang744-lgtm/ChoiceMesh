## 1. AI 的唯一工作

AI 只将当前成员主动提交的文字或语音转写整理成**仅本人可见、可编辑、不可自动确认**的条件草稿。

```text
成员输入 / 语音转写
  → 服务端调用 AI
  → Schema 验证
  → 成员查看、编辑与确认私密草稿
  → 共同页面仅接收匿名状态
```

## 2. AI 可以做什么

- 从一句话中识别可参加性、时间、通勤、预算、偏好和预计确认时间；
- 对模糊措辞输出 `needs_verification` 或较低置信度，而不是猜测为确认；
- 生成简洁、忠实于原意的私密摘要；
- 在结构不完整或自相矛盾时要求成员补充或编辑。

## 3. AI 不可以做什么

- 推荐活动、地点、候选方案或路线；
- 计算共同可行性、排序或发布资格；
- 读取、比较或泄露其他成员的私密条件；
- 代替成员确认参加、无法参加、支持变更或发布；
- 将提醒、沉默或预计确认时间转换为状态变化；
- 生成预订、支付、催促或群体沟通决定。

共同可行性、边界风险、提案支持和发布门槛全部由确定性规则引擎与服务端事务处理。

## 4. 数据与安全边界

- 原文、AI 草稿和精确数值为私密数据；
- 提示词不得注入其他成员原文、身份、精确住址或聊天记录；
- `DEEPSEEK_API_KEY` 仅存在于服务端环境变量，不能提交到 GitHub 或返回浏览器；
- AI 输出必须通过 JSON Schema 和服务端数字范围校验；
- AI 不可用时，成员仍应能采用手动结构化输入完成确认。
