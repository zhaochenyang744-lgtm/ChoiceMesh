## 目录结构

```text
EVIDENCE LENS/
├─ _系统/                       # 项目导航与命名规则
├─ 产出/
│  ├─ 规划文档/
│  │  ├─ Spec文档/              # 产品范围、需求、信息架构
│  │  ├─ AI工程/                # AI 边界、架构、提示词契约、评测、降级与演示证据
│  │  │  └─ 评测报告/           # 每次真实评测的归档，按日期
│  │  ├─ 用户研究/              # 研究计划与综合结论
│  │  ├─ 测试与评测/            # 可用性测试方案
│  │  ├─ 产品迭代/              # 版本规划
│  │  ├─ 技术验证/              # 技术方案、后端契约、实现状态
│  │  └─ 里程碑文档/            # 路线图与作品集证据规划
│  ├─ 设计文档/                 # 用户体验与视觉设计
│  └─ 交付物/
│     ├─ 产品原型/              # 六个迭代版本，V3 为当前基线
│     └─ 作品集案例/            # 待产出
├─ choicemesh-mvp/              # Next.js 实现、Supabase schema、AI 接口、评测脚本
├─ 参考资料/                    # 匿名原始记录（本地，不公开）
└─ 归档/                        # 已淘汰方向（本地，不公开）
```

每个目录下的 `历史版本/` 存放被新版本取代的文档，保留不删。

## 文件归类规则

- 原始访谈、测试原话与匿名记录只放入 `参考资料/用户研究原始材料/`；不在综合文档中改写为未经证实的事实
- 研究综合与需求决策放入 `产出/规划文档/`；引用原始材料时保留参与者编号和样本限制
- 可运行网页、原型、测试脚本和可再生成截图放入 `产出/交付物/产品原型/`
- AI 的边界、契约、评测与安全放入 `产出/规划文档/AI工程/`
- 不再参与当前产品决策的材料移入 `归档/`，不删除历史证据

命名与版本的具体规则见 [文档命名与版本规则](./文档命名与版本规则.md)。
